# Certificate Distribution System

Web application developed during an internship to help manage and track certificate deliveries to trainees.

## Purpose

The system allows a tutor to import Excel/XLSM files containing trainee data and store records of certificates that have already been sent.

This makes it possible to consult the delivery history later and quickly verify which trainees have already received their certificates.

## Features

- Excel and XLSM file import
- Automatic trainee data extraction
- Storage of trainee records in a MySQL database
- Certificate delivery history
- Search and consultation of previously processed trainees
- Imported data validation
- Duplicate record prevention
- Interface for viewing processed trainees
